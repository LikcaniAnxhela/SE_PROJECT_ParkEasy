# ParkEasy – Smart Parking Management System

## Project Overview
ParkEasy is a web-based parking management system designed to simplify parking space availability, reservations and administration within a managed parking facility.

## Main Features
- User registration and authentication
- Parking space availability search
- Parking reservations and cancellations
- Prevention of overlapping reservations
- Administrative parking space management
- Booking management

## Technologies
- Frontend: HTML, CSS, JavaScript
- Backend: Python, Flask
- Database: MySQL
- Version Control: Git and GitHub
- System Modelling: UML and C4

## System Architecture
ParkEasy follows a three-layer architecture with a modular monolith structure and the Model-View-Controller (MVC) pattern.

## Development Methodology
